# ⚡ 06 — Oracle RAC & Grid Infrastructure

## 📌 Overview
Deploys scalable, fault-tolerant clustered database architecture using Oracle Grid Infrastructure and Real Application Clusters (RAC).

## 🛠️ Key Technical Tasks & Implementation
* **Grid Infrastructure:** Installed and configured Oracle Clusterware and High Availability Services (OHAS).
* **ASM Storage Configuration:** Deployed Automatic Storage Management (ASM) disk groups for shared storage management.
* **Network & SCAN Setup:** Configured Single Client Access Name (SCAN) listeners and virtual IP (VIP) addresses.
* **Multi-Instance Lifecycle:** Deployed multi-instance database nodes with load balancing and failover capabilities.
