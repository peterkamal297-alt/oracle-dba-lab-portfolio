# 💾 04 — RMAN Backup & Recovery

## 📌 Overview
Implements robust enterprise data protection and disaster simulation recovery workflows utilizing Oracle Recovery Manager (RMAN).

## 🛠️ Key Technical Tasks & Implementation
* **Backup Strategies:** Configured and executed full Level 0 and incremental Level 1 database backups.
* **Fast Recovery Area (FRA):** Sized, configured, and managed FRA disk quotas for automated backup retention and archiving.
* **Archive Log Management:** Monitored archivelog generation, manual switching, and deletion policies.
* **Disaster Recovery & PITR:** Simulated data loss scenarios and performed complete recovery and Point-in-Time Recovery (PITR).
