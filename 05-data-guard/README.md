# 🔄 05 — Oracle Data Guard

## 📌 Overview
Configures high availability (HA) and disaster recovery (DR) solutions by maintaining synchronized physical standby databases.

## 🛠️ Key Technical Tasks & Implementation
* **Primary-Standby Architecture:** Established primary and physical standby database environments.
* **Redo Transport & Standby Logs:** Configured network redo transport services and standby redo log files.
* **Managed Recovery:** Enabled real-time apply mode using the Managed Recovery Process (MRP).
* **Broker & Failover Testing:** Configured Oracle Data Guard Broker and executed controlled switchover and failover validations.
